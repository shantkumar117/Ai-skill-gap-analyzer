About the project

A small tool for a big question.

AI Skill Gap Analyzer helps students turn a broad career goal into a realistic learning plan.

01 / Problem

Where should I focus?

Students often collect tutorials without knowing which skills matter most for a target role. This application compares current skills with a clear role database.

02 / Objective

Make learning actionable.

The result is a simple score, a visible skill gap, a priority order, and projects that can become portfolio evidence.
