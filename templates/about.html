About the project

A small tool for a big question.

AI Skill Gap Analyzer helps students and professionals turn a broad career goal into a realistic, step-by-step learning plan. It compares your current skills against any target software role, reveals the gap, and delivers an AI-powered roadmap with portfolio projects and interview readiness tips.

01 / Problem

Where should I focus?

Many learners collect tutorials without knowing which skills matter most for their target role. This tool compares current skills with a clear role database and discovers missing competencies — so you stop guessing and start building.

02 / Objective

Make learning actionable.

The result is a simple score, a visible skill gap, a priority order, and projects that can become portfolio evidence. It works for beginners choosing a first path and for experienced professionals switching careers.

03 / Built with

Python + Flask SQLite database HTML + CSS + JavaScript Chart.js visualization AI recommendations (Gemini / Anthropic / OpenAI)

Who this is for

Students deciding between frontend, backend, AI/ML, data, DevOps, or cybersecurity. Career-changers moving into software from another field. Self-taught developers looking for a structured path to a first job. Hiring managers and educators who want a common framework for skills conversation.

Frequently asked questions

How does the skill gap analysis work?

You enter your current skills and a target role. The tool compares them, calculates a match percentage, lists missing skills by priority, and produces a phased roadmap with action plans and portfolio ideas.

Can I use a custom role?

Yes. Choose from preset roles or type any custom role — the AI discovers required skills dynamically and caches them for future lookups.

Is my data private?

Yes. Analyses are stored per account, can be deleted manually, and older entries are automatically cleaned up after 30 days unless kept permanently.

Can I export results?

Yes. Export a professional PDF or DOCX report with metrics, recommendations, and the full roadmap.
