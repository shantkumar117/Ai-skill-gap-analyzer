# AI Skill Gap Analyzer

A modern Flask and SQLite web application that assesses a student's technical skillset against target software roles, discovers their skill gaps, and delivers **100% AI-powered personalized recommendations** — a phased learning pathway, skill-by-skill action plans with time estimates, tailor-made portfolio project blueprints, and interview readiness insights.

## Features

- **Any Target Job Role:** Choose from preset roles or type any custom role — AI Engineer, DevOps Lead, Cybersecurity Specialist, Cloud Architect, and beyond.
- **Two Analysis Paths:**
  - **Manual Entry** (`/analyze`): Enter current skills, select target role, get personalized gap analysis + roadmap.
  - **Resume Upload** (`/resume`): Upload or paste your resume — AI extracts skills, reviews your resume quality (ATS keywords, formatting, strengths/weaknesses), and generates a combined gap analysis.
- **100% AI-Powered Recommendations:** Every recommendation is generated by a live AI model (Anthropic Claude, Google Gemini, or OpenAI) — no rule-based output in the recommendation path. If no API key is configured, structured synthesis is used only as a final fallback within each provider call.
- **Dynamic Role Skill Discovery:** For custom roles not in the preset list, AI dynamically determines the required skills and caches them to SQLite for future lookups.
- **Fuzzy Skill Matching:** AI-discovered skills are intelligently matched against your current skills even when names differ slightly.
- **Structured AI Output:** Recommendations include a strategic summary, phased learning pathway, targeted skill action plans, custom portfolio project blueprints, and interview tips.
- **Resume Review Section** (when using `/resume`): AI analyzes your resume for strengths, weaknesses, missing ATS keywords, and formatting suggestions.
- **Interactive Visual Dashboard:** Responsive layout with match percentage progress bar, Chart.js doughnut chart, and quick-add skill chips.
- **SQLite Database:** Stores users, skills, role requirements, user skills, and analysis reports with JSON serialization.

## Installation and Run

Open a terminal in this directory. The commands below work in Windows PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser. The database is initialized and seeded automatically at `database/skill_gap.db` on startup.

## Environment Configuration (Optional for Live AI Models)

To enable live LLM generation, create a `.env` file in the project root with any of the following API keys:

```ini
# Anthropic Claude (Recommended)
ANTHROPIC_API_KEY=your_anthropic_api_key
ANTHROPIC_MODEL=claude-3-5-sonnet-20241022

# Google Gemini
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.0-flash

# OpenAI
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4o-mini
```

> **Note:** The app tries providers in order (Anthropic → Gemini → OpenAI). The first available provider generates your recommendations.

## Usage Paths

### Path 1: Manual Skill Entry (`/analyze`)
1. Enter your name and experience level
2. Choose a preset role or type a custom role
3. List your current skills (comma-separated)
4. Optionally add a career focus (e.g., "Cloud APIs", "AI applications")
5. Get a personalized roadmap with learning phases, skill action plans, and portfolio projects

### Path 2: Resume Analysis (`/resume`)
1. Choose a target role (preset or custom)
2. Upload a resume (PDF, DOCX, TXT) or paste resume text
3. AI extracts your skills and reviews your resume:
   - **Resume Strengths:** Highlighted competencies
   - **Areas to Improve:** Actionable feedback
   - **Missing ATS Keywords:** Technical terms to boost discoverability
   - **Formatting Notes:** Layout and presentation advice
4. Get the same personalized roadmap, plus skill gap analysis
